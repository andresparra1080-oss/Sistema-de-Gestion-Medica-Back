# Sistema-de-Gestion-Medica-y-Emergencias-para-la-Tripulacion-de-Trafalgar-Law-
Sistema de gestión médica naval y emergencias para la tripulación de Trafalgar Law (Piratas Heart) a bordo del Polar Tang. Permite control de historias clínicas, gestión e inventario de medicamentos, alertas automáticas en tiempo real, respuesta ante combates/epidemias y panel de control para el Capitán.

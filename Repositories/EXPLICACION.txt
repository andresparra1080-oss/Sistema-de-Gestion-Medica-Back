CAPA: Repositories

Responsabilidad:
La capa de Repositories abstrae el acceso a datos. Aquí se definen las consultas, inserciones, actualizaciones, eliminaciones y cualquier operación CRUD que interactúe con la base de datos o una fuente externa de persistencia.

Qué tipo de archivos van aquí:
- interfaces de repositorio por entidad
- implementaciones concretas para SQL o SGBD
- consultas parametrizadas y mapeo a modelos del dominio
- adaptadores para bases de datos y sistemas externos

Buenas prácticas de diseño:
- No mezclar acceso a datos con lógica de negocio.
- Centralizar las consultas SQL o sentencias del sistema.
- Hacer uso de parámetros y evitar interpolación directa de datos.
- Mapear las entidades de persistencia a modelos de negocio o DTOs.
- Mantener operaciones CRUD consistentes y reutilizables.
- Definir contratos claros para facilitar pruebas y reemplazos de infraestructura.

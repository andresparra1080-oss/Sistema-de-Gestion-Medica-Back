CAPA: Database

Responsabilidad:
La capa de Database concentra la configuración, conexión y gestión del almacenamiento persistente del sistema. Aquí se define la infraestructura del SGBD, scripts de inicialización, migraciones y cualquier lógica para arrancar la base de datos de forma reproducible.

Qué tipo de archivos van aquí:
- archivos de conexión y configuración del SGBD
- scripts SQL de creación de tablas y seed data
- migraciones y versionado de esquema
- utilidades para inicializar, validar y probar la base de datos

Buenas prácticas de diseño:
- Mantener las migraciones versionadas y reversibles.
- Separar scripts de esquema, datos iniciales y cambios incrementales.
- Usar variables de entorno para credenciales y configuración.
- Evitar hardcodear datos de producción en el código.
- Documentar claramente el modelo y las dependencias del sistema.
- Centralizar la inicialización para facilitar despliegues y pruebas automatizadas.

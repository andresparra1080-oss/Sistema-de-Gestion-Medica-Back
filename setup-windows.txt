Instalacion y ejecucion del proyecto en Windows

REQUISITOS:
- Windows 10 o 11
- Git
- MSYS2 instalado
- MinGW 64-bit
- CMake
- Acceso a internet para descargar dependencias

Este backend usa:
- Crow (HTTP server)
- SQLite3
- OpenSSL (SHA-256 para hashes de contraseñas)
- nlohmann/json

------------------------------------------------------------
PASO 1: Instalar MSYS2
------------------------------------------------------------
1. Descarga MSYS2 desde:
   https://www.msys2.org/

2. Instala MSYS2 en una ruta corta, por ejemplo:
   C:\msys64

3. Abre la terminal "MSYS2 MSYS" y ejecuta:
   pacman -Syu

4. Cierra la terminal y vuelve a abrirla.

5. Ejecuta esta instalacion base:
   pacman -S --needed base-devel mingw-w64-x86_64-toolchain git cmake

6. Abre la terminal "MSYS2 MinGW 64-bit" para compilar el proyecto.

------------------------------------------------------------
PASO 2: Instalar dependencias del proyecto
------------------------------------------------------------
En la terminal MinGW 64-bit ejecuta:
   pacman -S --needed mingw-w64-x86_64-asio mingw-w64-x86_64-openssl mingw-w64-x86_64-sqlite3

Opcional dependiendo del entorno:
   pacman -S --needed mingw-w64-x86_64-boost

------------------------------------------------------------
PASO 3: Clonar el proyecto
------------------------------------------------------------
   git clone <URL-del-repositorio>
   cd <carpeta-del-proyecto>

------------------------------------------------------------
PASO 4: Configurar con CMake
------------------------------------------------------------
Desde la carpeta del proyecto ejecuta:
   cmake -S . -B build -G "MinGW Makefiles"

Si quieres forzar el compilador manualmente:
   cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_CXX_COMPILER=C:/msys64/mingw64/bin/g++.exe

INSTRUCCIONES PARA COMPILAR Y EJECUTAR HEARTMED BACKEND EN WINDOWS

------------------------------------------------------------
REQUISITOS
------------------------------------------------------------
- Instalar MSYS2
- Abrir MSYS2 MinGW 64-bit
- Instalar dependencias:
  pacman -Syu
  pacman -S --needed base-devel mingw-w64-x86_64-toolchain git cmake mingw-w64-x86_64-asio mingw-w64-x86_64-openssl mingw-w64-x86_64-sqlite3

------------------------------------------------------------
PASO 1: IR A LA CARPETA DEL PROYECTO
------------------------------------------------------------
PowerShell:
  cd "C:\Users\andre\Documents\HeartPirates\HeartMedBack"

------------------------------------------------------------
PASO 2: LIMPIAR CACHE ANTIGUA DE CMAKE
------------------------------------------------------------
PowerShell:
  Remove-Item -Recurse -Force build -ErrorAction SilentlyContinue

------------------------------------------------------------
PASO 3: CONFIGURAR EL PROYECTO CON MINGW
------------------------------------------------------------
PowerShell:
  $env:Path = "C:\msys64\mingw64\bin;C:\msys64\usr\bin;" + $env:Path
  & "C:\Program Files\CMake\bin\cmake.exe" -S . -B build -G "MinGW Makefiles" -DOPENSSL_ROOT_DIR="C:/msys64/mingw64" -DCMAKE_MAKE_PROGRAM="C:/msys64/mingw64/bin/mingw32-make.exe" -DCMAKE_CXX_COMPILER="C:/msys64/mingw64/bin/g++.exe"

------------------------------------------------------------
PASO 4: COMPILAR
------------------------------------------------------------
PowerShell:
  & "C:\Program Files\CMake\bin\cmake.exe" --build build --config Release

Verificacion esperada:
  [100%] Built target heartmed-backend

------------------------------------------------------------
PASO 5: EJECUTAR LA API
------------------------------------------------------------
PowerShell:
  $env:Path = "C:\msys64\mingw64\bin;C:\msys64\usr\bin;" + $env:Path
  .\build\heartmed-backend.exe

Si quieres usar un puerto distinto:
  $env:PORT = "3000"
  .\build\heartmed-backend.exe

------------------------------------------------------------
PASO 6: COMPROBAR SI SIGUE FUNCIONANDO
------------------------------------------------------------
PowerShell:
  Invoke-WebRequest http://localhost:18080/health

Si falla, la API ya no está levantada o se cerró.
Tambien puedes probar:
  Invoke-WebRequest http://localhost:18080/api/health

------------------------------------------------------------
PASO 7: PROBAR LOGIN
------------------------------------------------------------
Endpoint:
  POST http://localhost:18080/login

JSON:
  {
    "email": "law@heartpirates.com",
    "password": "Prueba123*"
  }

PowerShell:
  Invoke-RestMethod -Uri "http://localhost:18080/login" -Method Post -ContentType "application/json" -Body '{"email":"law@heartpirates.com","password":"Prueba123*"}'

------------------------------------------------------------
IMPORTANTE
------------------------------------------------------------
- Si la API no responde en http://localhost:18080/health, entonces no está funcionando.
- Si CMake falla por OpenSSL, usa -DOPENSSL_ROOT_DIR="C:/msys64/mingw64".
- La ruta de la carpeta debe mantener el mismo nombre: HeartMedBack.
- El ejecutable se genera en:
  .\build\heartmed-backend.exe

------------------------------------------------------------
COMANDO FINAL
------------------------------------------------------------
$env:Path = "C:\msys64\mingw64\bin;C:\msys64\usr\bin;" + $env:Path

& "C:\Program Files\CMake\bin\cmake.exe" --build build --config Release
